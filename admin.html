⚙️ Connexion GitHub (publication du fichier data/conferences.json)

GitHub Pages est un hébergement statique : pour écrire réellement la « base », l'admin commit le fichier JSON dans le dépôt via l'API GitHub. Créez un jeton fine-grained limité à ce dépôt avec la permission Contents : Read and write.

⚠️ Le jeton reste dans votre navigateur et n'est jamais committé. Utilisez un jeton fine-grained, limité à ce seul dépôt, et révoquez-le en cas de doute.

« Publier sur GitHub » commit data/conferences.json dans le dépôt : le workflow GitHub Actions redéploie alors le site pour tous les visiteurs. « Enregistrer le brouillon » ne modifie que votre navigateur.
